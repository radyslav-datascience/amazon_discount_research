# CLAUDE.md — Інструкції для Claude Code

## Короткий опис проекту

Цей проект присвячений оптимізації знижок для Double Pack продуктів на Amazon US marketplace з метою максимізації чистого прибутку. Використовується data-driven підхід з машинним навчанням для розробки оптимальної цінової стратегії на основі аналізу історичних даних про Sessions, Orders та Sales.

Проект створено для демонстрації компетенцій у Data Science та Business Analytics в контексті e-commerce аналітики.

## Основні файли проекту

### Скрипти обробки даних (`src/data_scripts/`)

- **mass_product_aggregation.py** — масова агрегація даних Single vs Double Pack
- **mass_product_kpi.py** — розрахунок 7 ключових KPI метрик

### ML модель (`src/models_training/`)

- **amazon_dp_dr_model_production.py** — продакшн модель оптимізації знижок (7 методів A-G)

### Ключові метрики проекту

- **DP_DR** — Double Pack Discount Rate (рівень знижки)
- **DP_CR** — Conversion Rate (коефіцієнт конверсії)
- **DP_TAR** — Traffic Attraction Rate (залучення трафіку)
- **DP_CSC** — Cross-Single Conversion (крос-конверсія)
- **DP_NPS** — Net Profit Share (частка чистого прибутку)
- **DP_NPPS** — Net Profit Per Session DP (прибуток на сесію DP)
- **DP_CSPPS** — Cross-Single Pack Profit per Session (прибуток на сесію SP)

## Методологія

Проект використовує:
- **Polynomial Regression** (3rd order) для моделювання залежностей
- **scipy.optimize.minimize_scalar** для пошуку оптимальних знижок
- **7 Methods (A-G)** — різні підходи до оптимізації через різні KPI
- **Validation Metrics:** MAPE, RMSE, R² для оцінки якості моделей
